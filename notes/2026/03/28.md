# Hyperscraps: implicitly linked hypertext

I built a new static site generator / hypertext system for this website. It's called hyperscraps and it's powering the page that you're reading. Its main feature is that it's built on the idea of linking pages _implicitly_ through scraps of text with the same content hash. Wherever two or more documents share the same text block, they will be linked together.

But there are also jump links. For example, when I write `[[Staged programming and the principle of least power]]`, it shows up as [[Staged programming and the principle of least power]] and links directly to the page or the snippet with that content because there is a single unique snippet.
