Hyperscraps: implicitly linked hypertext

I built a new static site generator / hypertext system for this website. It's called hyperscraps and it's powering the page that you're reading. Its main feature is that it's built on the idea of linking pages implicitly through scraps of text with the same content hash. Wherever two or more documents share the same text block, they will be linked together.

But there are also jump links. For example, when I write [[Staged programming and the principle of least power]], it shows up as Staged programming and the principle of least power and links directly to the page or the snippet with that content because there is a single unique snippet.

But if there are multiple matching snippets, such as [[The captured liar]], it shows up as [[The captured liar]]: The link is not shown as a jump link, but rather as a collection of aside links after this paragraph:

  • RC week 17: test cases for paradoxical fixed points – The captured liar
  • RC week 19: a sketch for a time loop calculus, part 2 – The captured liar
  • RC week 22: paradoxical values as unordered time loop maps – The captured liar
