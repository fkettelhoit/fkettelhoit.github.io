# Kombucha

A minimal and malleable programming language.

[Kombucha](https://github.com/fkettelhoit/kombucha) is a minimal functional programming language that is meant to be used symbiotically within a larger ecosystem and in cooperation with a host language. It prioritizes malleability through flexible syntax and effect handlers.

It is an exploration of building a programming language as home-cooked software, small and personal, yet also useful. (Well, being useful is still a work in progress.)
